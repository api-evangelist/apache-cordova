We are happy to announce that cordova-common@6.0.0 has been released. This is one of the libraries used behind-the-scenes by nearly all of the Cordova tooling and provides utilities for dealing with things like config.xml parsing. Release Highlights The most notable changes in this major release were: Removal of superspawn , which also dropped the npm dependencies q and cross-spawn .
