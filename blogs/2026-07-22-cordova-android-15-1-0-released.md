We are happy to announce that we have just released Cordova Android 15.1.0 ! This is one of Cordova's supported platforms for building Android applications. cordova-android@15.1.0 To upgrade: cordova platform remove android cordova platform add android@15.1.0 To install: cordova platform add android@15.1.0 Release Highlights Features Deprecation of PermissionHelper The PermissionHelper class has been deprecated.
