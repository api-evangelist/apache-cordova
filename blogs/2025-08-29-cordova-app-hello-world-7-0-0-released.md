We are happy to announce that cordova-app-hello-world@7.0.0 has been released. This is the default app template used when creating a new Cordova App project though Cordova CLI. Release Highlights The most notable changes in this release were: Setting the body element's box-sizing to border-box to avoid the safe-area-inset padding that caused scrolling issues Disabled the overscroll behavior of the root element to remove rubber-banding effects.
